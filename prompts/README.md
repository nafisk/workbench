# Prompts

## Purpose
Raw prompt fragments that are not yet promoted to skills or commands.

## What Belongs Here
Experimental prompts, reusable snippets, and drafts.

## What Does Not Belong Here
Stable workflows that should be skills, secrets, or project facts.

## Portability
Plain Markdown. Consumers must copy, render, or wrap prompts for each tool.

## Provenance
Track externally sourced prompts before promoting them.

## Install Behavior
Not installed by default in v0.1.

## Examples
Draft review prompt, draft debugging prompt.
