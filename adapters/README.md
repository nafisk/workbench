# Adapters

## Purpose
Map shared assets into target-specific file layouts.

## What Belongs Here
Codex, Claude, and Gemini templates plus adapter-owned assets such as Claude commands.

## What Does Not Belong Here
Shared source guidance or active project files.

## Portability
Adapters are intentionally tool-specific.

## Provenance
Adapter templates are custom unless noted in `registry.yaml`.

## Install Behavior
Rendered by the Node CLI.

## Examples
`codex/AGENTS.md.tmpl`, `claude/CLAUDE.md.tmpl`.
