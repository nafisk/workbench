# Agents

## Purpose
Specialist personas or subagents for delegated work.

## What Belongs Here
Planner, architect, reviewer, tester, researcher, and similar focused roles.

## What Does Not Belong Here
General rules, install scripts, MCP secrets, or active project specs.

## Portability
Agent formats vary by tool. v0.1 documents this folder but does not install agents by default.

## Provenance
Track imported or adapted agents in `registry.yaml`.

## Install Behavior
Future adapters may copy or symlink agents into target-specific folders.

## Examples
`planner.md`, `architect.md`, `security-reviewer.md`.
