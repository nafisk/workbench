# Templates

## Purpose
Generic renderable file templates.

## What Belongs Here
Templates shared by more than one adapter or target.

## What Does Not Belong Here
Tool-specific adapter templates or active project specs.

## Portability
Depends on the renderer and target adapter.

## Provenance
Track imported templates in `registry.yaml`.

## Install Behavior
Rendered or copied by scripts.

## Examples
Future shared license headers, issue templates, or onboarding docs.
