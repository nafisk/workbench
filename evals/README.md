# Evals

## Purpose
Smoke tests and evaluation prompts for agent assets.

## What Belongs Here
Small tests that check workflow behavior, prompt boundaries, and regression scenarios.

## What Does Not Belong Here
Full app test suites or private project data.

## Portability
Mostly tool-neutral. Target-specific evals should be labeled.

## Provenance
Custom unless noted.

## Install Behavior
Not installed by default.

## Examples
Spec gate tests, one-task implementation tests, verification prompt tests.
