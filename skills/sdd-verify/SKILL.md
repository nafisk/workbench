# SDD Verify

Read:

- `requirements.md`
- `design.md`
- `tasks.md`
- `verification.md`
- relevant changed files

Check:

- Every completed task has evidence.
- Acceptance criteria are satisfied or explicitly marked as gaps.
- Verification commands are recorded.
- Missing tests or manual checks are listed.

Update `verification.md` with traceability. If all approved tasks and criteria are complete, update `state.yaml` to `phase: complete`.
