# Core

## Purpose
Shared guidance that should influence most agent sessions.

## What Belongs Here
Principles, global workflow rules, security baselines, testing baselines, and git workflow expectations.

## What Does Not Belong Here
Project architecture, product requirements, secrets, or tool-specific config.

## Portability
Rendered into Codex `AGENTS.md` and Claude `CLAUDE.md`.

## Provenance
Files are custom unless noted in `registry.yaml`.

## Install Behavior
Rendered into target guidance files.

## Examples
`principles.md`, `spec-driven-development.md`, `security-baseline.md`.
